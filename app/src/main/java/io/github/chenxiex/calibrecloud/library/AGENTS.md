# 图书馆查询约束

- 查询只读取最后一次有效导入（`ImportedLibrary`）和最小下载清单，不访问存储后端、网络或任务队列，不提交任务；没有完整导入时返回 `NO_METADATA`，不能用下载清单推断完整书库。
- `LibraryIndex` 以不可变内存索引服务一个 `LibraryRevision`（书库身份、导入代次、已读栏目配置）。新导入、换库、清元数据或保存栏目配置后，`LibraryQueryService` 在后台重建；请求携带的 `expected` 与当前不符时返回 `Stale`，旧结果不得填入新页面。不新增业务查询表，代表性规模实测不满足响应时再评估。
- 搜索只做大小写不敏感的字面包含匹配：按空白拆分关键词，全部命中才匹配（可跨字段），不解释 Calibre 搜索表达式，不拼接 SQL。非空搜索覆盖整个书库、保留筛选并平铺为书籍；简介使用导入时已去除标签的文字。
- 下载状态和已读状态筛选各为单值，格式筛选多个取“或”，跨维度取“且”。已下载指当前格式筛选范围内至少一个完整副本；已读栏目未配置或失效时返回 `READ_FILTER_UNAVAILABLE`，已读值为空，不把整库判为未读。
- 分类先筛选后分组；多值让同书进入多个文件夹，无值进入最后的兜底文件夹，空结果不生成兜底。文件夹只按名称排序（`foldersAscending` 切换方向，兜底文件夹始终最后），代表书籍为加入时间最新者；仅文本、枚举和多值文本栏目可分类或限定搜索。书籍排序以标题、书籍 ID、UUID 作稳定次序，空评分／空序号始终在后。
- 默认格式先在格式筛选范围内按优先级选完整缓存，没有缓存再选源格式；大小未知为 null，不以 0 表示。用户可见原因只以稳定枚举暴露，由页面解析资源；不得在日志记录书名、作者或搜索词。
- 选择展开（`expand`）与页面查询共用同一搜索、筛选与分类规则：直接选中的书籍只在仍属于当前层级且仍匹配时计入，选中的文件夹展开为其中实际匹配的书籍，跨文件夹按完整身份去重。每本书的批量下载格式是格式筛选范围内按优先级的第一个源格式，不因已缓存其它格式而改变；无源格式为 null。阅读状态标记由 `ReadMarkChoice.of` 判定：每本书取最后一次成功导入的状态，再以调用方传入的待写入目标覆盖（R26、Q81；失败的写回不计入），全已读为“标为未读”，全未读含空值或混合为“标为已读”；集合为空、栏目无效或调用方给出的源写入原因（`WRITE_*`，由界面从 `writeCapability` 映射，本包不依赖存储接口）时禁用。待写入目标不进入索引的筛选、搜索与排序。展开结果由调用方在提交时冻结，之后的导入不追加书籍。
- `LibraryQueryService.overview()` 只返回导入时间、可分类／限定搜索的栏目、已读筛选是否可用及导入中的源格式，供页面标题、分类菜单、字段徽标、筛选面板和上次同步显示，不读取行数据。
