# 界面约束

适用于 `ui/`，遵循 [R20 总体布局与墨水屏交互](../../../../../../../../../spec.md#r20--总体布局与墨水屏交互) 及 [app/AGENTS.md](../../../../../../../../AGENTS.md)。

- 内容不通过滚动或惰性列表遍历；超出一页的列表、网格、菜单和弹窗都放进 `PagedArea`：它统一提供滑动翻页（左→右或上→下为上一页，反向为下一页，按位移较大方向判定，抬手后一次翻页，超过触控阈值的拖动不再算点击）和下方的 `PageBar`，各模块不另写翻页控件或手势。网格和列表按数量优先计算页容量（`gridGeometry`／`listGeometry`）：先放下尽可能多的最小单元格，再把单元格放大填满一个方向，余量均分为间距，至少一项；行高不同的分组菜单用 `paginate` 按高度分页，标题不落在页尾、分割线不出现在页首／页尾。翻页行统一用 `PageBar`（首页、上一页、“当前页 / 总页数”、下一页、末页），首页／末页禁用对应方向；菜单只有一页时不显示翻页行。尺寸变化后页偏移由 `firstVisible` 重新对齐（`pageStart`），不丢失当前首个可见项所在页。
- 不使用过渡、点击涟漪、加载旋转或带动画的 Material 组件（如 `DropdownMenu`、`AlertDialog`、系统 `Dialog`）；菜单是占用内容区的分页面板，弹窗是同一窗口内的覆盖层，点击使用无指示器的 `clickable`。视图菜单切换选项后保持打开，由视图按钮或系统返回关闭。
- 常用操作用 `IconAction` 图标按钮（48dp 触控区、资源化无障碍描述）：禁用为灰色，激活（如菜单打开时的视图按钮）为黑底白图标；菜单选中项加粗并在行尾显示勾选或排序方向箭头，底栏当前页用实心图标和粗体文字，灰度下不依赖色相。文字按钮 `StaticButton` 仍用于“更多”临时页和说明性操作。
- 图标是 `res/drawable/ic_*.xml` 矢量资源，不引入图标库依赖。除自绘的 `ic_more_*` 外取自 Material Icons（Apache-2.0），文件头注明来源；关于页的第三方声明须列出该来源。
- 文案、无障碍描述和动态值使用字符串／数量资源及完整占位参数；作者、大小等未知字段不显示占位文字，不以零值伪装。
- 关键控件设置稳定的 `testTag`，`MainScreen` 根节点开启 `testTagsAsResourceId`，使 UI 测试和 ADB helper 按资源 ID 选择，不依赖页码或位置；重复条目的标签含稳定标识（如 `book_<书籍 ID>`）。
- `LibraryViewModel` 只通过 `LibraryQueryService` 读本地索引，页面请求带 `expected` 修订，过期结果丢弃；只为当前页（含文件夹代表书籍）缺失的封面经 `CoverService` 入队，同一显示页不重复入队，不预取隐藏页；选中书库或导入变化后清空旧封面。视图状态保存在 ViewModel，Activity 重建后保持，不扩展为跨进程持久化。
- 搜索页是 `LibraryViewModel` 的 `SearchSession`：进入时复制图书馆的视图、书籍排序（丛书序号除外）与筛选，修改只写入会话；图书馆的分类、文件夹和页码不变，`closeSearch` 恢复。输入文字保存在 ViewModel，只有键盘搜索键（或点历史项）调用 `submitSearch` 执行并经 `SearchHistoryStore` 记录；输入清空回到字段徽标与历史。筛选面板和视图菜单都占用内容区、互斥，切换选项后保持打开。
- 外部打开由 Activity 级 `OpenViewModel` 负责，只保留最近一次单本单格式意图：新的点击、离开当前页（切换底栏）、Activity `onStop`（配置变更除外）及选择代号变化都会撤销；被撤销的下载继续在队列中完成，但不会打开阅读器。只有仍为当前意图、应用在前台且选择代号未变时才生成 `OpenLaunch`，由 `MainScreen` 调用注入的启动函数并回报结果；只有 `STARTED` 才写入上次打开。`OpenViewModel.mark` 在该书下载勾选的位置（网格封面右下角、列表行右侧）绘制黑底圆形图标：下载中为略小的白叉圆盘加紧贴其外缘的静态进度弧（合计与下载勾等大，无轨道和边框线），进度最多每 2 秒变化一次，点击经队列取消下载任务并撤销意图（任务尚未返回时在返回后取消）；需要用户处理的等待（等待条件、暂停）改为感叹号并保留进度弧和取消；失败为不带进度弧、不单独响应点击的感叹号，点击书籍即重新打开。页面内不显示原因文字或状态条：每个新的需处理状况产生一个 `OpenNotice`，由 `MainActivity` 经 `OpenNotifications` 以单条可替换的系统通知发送（首次缺少权限时先请求），读者启动或用户取消时撤回；通知按 `openMoreTarget` 带上登录、目录授权或同步页，点击后由 `MainScreen` 的 `moreRequest` 打开。批量操作不得创建打开意图。没有当前意图的书只要有未结束的副本下载任务，就按 `OpenViewModel.downloads`（来自 `BookOpening.downloads` 的任务事件）显示同样的下载中图标，点击经 `cancelTask` 取消该任务；意图的标记优先。
- 第二阶段临时验证页保留在“更多”下，供后端、清理和任务能力使用；正式更多页在第三阶段步骤 07 替换它们。
