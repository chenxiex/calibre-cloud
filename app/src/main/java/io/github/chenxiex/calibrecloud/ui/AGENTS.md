# 界面约束

适用于 `ui/`，遵循 [R20 总体布局与墨水屏交互](../../../../../../../../../spec.md#r20--总体布局与墨水屏交互) 及 [app/AGENTS.md](../../../../../../../../AGENTS.md)。

- 内容不通过滚动或惰性列表遍历；超出一页的列表、网格、菜单和弹窗都放进 `PagedArea`：它统一提供滑动翻页（左→右或上→下为上一页，反向为下一页，按位移较大方向判定，抬手后一次翻页，超过触控阈值的拖动不再算点击）和下方的 `PageBar`，各模块不另写翻页控件或手势。网格和列表按数量优先计算页容量（`gridGeometry`／`listGeometry`）：先放下尽可能多的最小单元格，再把单元格放大填满一个方向，余量均分为间距，至少一项；行高不同的分组菜单用 `paginate` 按高度分页，标题不落在页尾、分割线不出现在页首／页尾。翻页行统一用 `PageBar`（首页、上一页、“当前页 / 总页数”、下一页、末页），首页／末页禁用对应方向；菜单只有一页时不显示翻页行。尺寸变化后页偏移由 `firstVisible` 重新对齐（`pageStart`），不丢失当前首个可见项所在页。
- 不使用过渡、点击涟漪、加载旋转或带动画的 Material 组件（如 `DropdownMenu`、`AlertDialog`、系统 `Dialog`）；菜单是占用内容区的分页面板，弹窗是同一窗口内的 `OverlayPanel`（无遮罩，点面板外或系统返回关闭），点击使用无指示器的 `Modifier.tap`，主题另把 `LocalIndication` 设为不绘制。覆盖层打开时其下方的页面节点不在无障碍树中，ADB helper 会把面板下仍可点击的节点视为遮挡，需要时按其坐标规则操作。视图菜单切换选项后保持打开，由视图按钮或系统返回关闭。
- 视觉风格统一（R20，Q64–Q68）：颜色、尺寸、圆角、字体和无按压指示的点击（`Modifier.tap`）只取自 `Theme.kt`，`MainActivity` 用 `CalibreCloudTheme` 包裹全部页面；同一用途的控件只用 `Components.kt` 与 `Menu.kt` 的共享实现（顶栏 `TopBar`／`TopBarTitle`／`BackAction`、图标按钮 `IconAction`／`IconSlot`、文字按钮 `ActionButton`、`ChoiceChip`、`SelectionMark`、`TagLabel`、`ListItem`、`Heading`、`FormColumn`、`EmptyMessage`、覆盖层 `OverlayPanel`／`ConfirmPanel`、`SearchField`、分割线 `HorizontalRule`／`InsetRule`、菜单行 `MenuEntry`／`MenuRow`／`PagedEntries`），页面不直接写颜色、圆角、零散 dp／sp 或 `clickable`；只有一个页面需要的尺寸（如 R27 网格单元、R28 状态图标、已读斜幅）在该页面以具名常量声明。可点击元素的触控区不小于 48dp，图标 24dp（顶栏搜索图标按 R21 为 20dp），页面边距 12dp、分节间距 8dp，单行行高 48dp、两行 56dp，顶栏和翻页行 48dp。
- 选中与按钮（Q65、Q67）：徽标、标签和分段选择用 `ChoiceChip`，选中为黑底白字加粗；菜单和列表的选项在行首用 `SelectionMark`（单选为圆形，多选为方框）并加粗选中项，排序方向等附加状态在行尾（`MenuEntry.Choice.trailing`）；激活的 `IconAction`（如菜单打开时的视图按钮）为黑底白图标，禁用为灰色；底栏当前页用实心图标和粗体文字。`ActionButton` 分三级：`PRIMARY` 黑底白字，每页最多一个，含说明后果的危险操作；`SECONDARY` 细边框；`TEXT` 用于取消、返回和顶栏的“完成”；不用浅色 tonal 按钮，禁用时去掉填充并变灰。按钮、输入框、选项块、卡片、菜单和覆盖层 4dp 圆角，徽标与标签为胶囊形，状态图标为圆形（Q68）。
- 图标是 `res/drawable/ic_*.xml` 矢量资源，不引入图标库依赖。除自绘的 `ic_more_*` 外取自 Material Icons（Apache-2.0），文件头注明来源；关于页的第三方声明须列出该来源。
- 文案、无障碍描述和动态值使用字符串／数量资源及完整占位参数；作者、大小等未知字段不显示占位文字，不以零值伪装。
- 关键控件设置稳定的 `testTag`，`MainScreen` 根节点开启 `testTagsAsResourceId`，使 UI 测试和 ADB helper 按资源 ID 选择，不依赖页码或位置；重复条目的标签含稳定标识（如 `book_<书籍 ID>`）。
- `LibraryViewModel` 只通过 `LibraryQueryService` 读本地索引，页面请求带 `expected` 修订，过期结果丢弃；只为当前页（含文件夹代表书籍）缺失的封面经 `CoverService` 入队，同一显示页不重复入队，不预取隐藏页；选中书库或导入变化后清空旧封面。视图状态保存在 ViewModel，Activity 重建后保持，不扩展为跨进程持久化。
- 没有完整元数据时，`LibraryViewModel.syncing` 给出当前选择未完成的书库同步（经 `latestLibrarySync` 读队列，与“更多”的同步状态同源），图书馆页据此显示正在同步／等待并以“查看同步状态”代替“同步元数据”；此状态下也跟随书库同步任务的变化重读。
- 搜索页是 `LibraryViewModel` 的 `SearchSession`：进入时复制图书馆的视图、书籍排序（丛书序号除外）与筛选，修改只写入会话；图书馆的分类、文件夹和页码不变，`closeSearch` 恢复。输入文字保存在 ViewModel，只有键盘搜索键（或点历史项）调用 `submitSearch` 执行并经 `SearchHistoryStore` 记录；输入清空回到字段徽标与历史。筛选面板和视图菜单都占用内容区、互斥，切换选项后保持打开。
- 外部打开由 Activity 级 `OpenViewModel` 负责，只保留最近一次单本单格式意图：新的点击、离开当前页（切换底栏）、Activity `onStop`（配置变更除外）及选择代号变化都会撤销；被撤销的下载继续在队列中完成，但不会打开阅读器。只有仍为当前意图、应用在前台且选择代号未变时才生成 `OpenLaunch`，由 `MainScreen` 调用注入的启动函数并回报结果；只有 `STARTED` 才写入上次打开；`MainScreen` 在切换底栏、回到前台及书库列表 `revision` 变化（更多页切换、添加或移除书库）时调用 `refresh` 重新读取当前书库的记录。`OpenViewModel.mark` 在该书下载勾选的位置（网格封面右下角、列表行右侧）绘制黑底圆形图标：下载中为略小的白叉圆盘加紧贴其外缘的静态进度弧（合计与下载勾等大，无轨道和边框线），进度最多每 2 秒变化一次，点击经队列取消下载任务并撤销意图（任务尚未返回时在返回后取消）；需要用户处理的等待（等待条件、暂停）改为感叹号并保留进度弧和取消；失败为不带进度弧、不单独响应点击的感叹号，点击书籍即重新打开。页面内不显示原因文字或状态条：每个新的需处理状况产生一个 `OpenNotice`，由 `MainActivity` 经 `OpenNotifications` 以单条可替换的系统通知发送（首次缺少权限时先请求），读者启动或用户取消时撤回；通知按 `openMoreTarget` 带上登录、目录授权或同步页，点击后由 `MainScreen` 的 `moreRequest` 打开。批量操作不得创建打开意图。没有当前意图的书只要有未结束的副本下载任务，就按 `OpenViewModel.downloads`（来自 `BookOpening.downloads` 的任务事件）显示同样的下载中图标，点击经 `cancelTask` 取消该任务；意图的标记优先。
- 选择模式（R26）由 `LibraryViewModel.selected` 表示，只收集当前层级（图书馆根、文件夹或搜索结果）的书籍与文件夹键：长按进入，选择中短按切换且不打开书籍或文件夹，翻页可继续选择；顶栏换成“完成”、实际书籍数、下载与更多，不提供搜索、筛选与视图入口。改变分类、文件夹、筛选或搜索以及换书库都结束选择，系统返回先关闭确认页或右上角的更多弹出菜单再结束选择。每次操作都按当前层级重新展开并冻结结果：批量下载经 `LibraryBatch` 逐书提交用户下载、跳过已有副本、统计无格式书籍，不创建打开意图；移除下载以当前格式筛选（无筛选为全部格式）调用精确清理预览，确认页显示冻结的书籍数、格式、副本数和字节，确认后执行同一计划。只有确有提交或移除成功才退出选择；页面不显示结果横幅或提示行（Q57），成功由书籍标记体现，未全部完成时 `LibraryViewModel.notice` 产生一个 `BatchNotice`，由 `MainActivity` 经 `BatchNotifications` 以单条可替换的系统通知发送，权限处理与打开通知共用。阅读状态标记在第四阶段前以“写回不可用”禁用。选中项同时有粗框和勾选框，不依赖颜色。
- “更多”（R30）是 `MoreScreen`：菜单用 `MenuEntry` 分组（元数据／存储与缓存／任务／设置／关于）交给 `PagedEntries`，子页为 `MorePage`，每页记录其上级，返回图标和系统返回回到上级；子页状态只在页面组合期间保存，切换底栏回到菜单。顶栏搜索图标只按名称过滤菜单项（含书库页下的“添加书库”），不检索书库，也不写搜索历史。图书馆和通知只传 `MoreTarget`（配置、目录授权和登录都映射到书库页，另有同步所在的菜单和已下载文件），由 `MorePage.of` 映射，不依赖页码。
- 更多页只读私有状态；源访问只来自显式的同步（`MetadataViewModel.synchronize`，经 `StartupSync.request` 高优先级提交并唤醒队列）、目录浏览／选择与登录。元数据分组依次说明未配置（附书库页入口）或无完整元数据，上次成功同步时间作为“立即同步”行的第二行；再按需显示当前选择最新同步任务的排队、等待、暂停、取消或失败原因。清理子页进入即预览范围，确认执行同一计划；已下载文件、任务队列和 OneDrive 目录列表按实测空间计算每页条数并使用 `PagedArea`。任务队列显示时先 `restorePending()`，再每两秒刷新。任务队列（`TaskList`，Q62）的“进行中／已完成”标签与“全部／用户请求／自动任务”筛选只在页面组合期间保存，切换时回到第一页；排队序号按整个队列计算，不随筛选变化；队列不记录完成时间，“已完成”按调度序号倒序（Q63，提升后的任务用提升时的序号）。任务行为 56dp 的两行 `ListItem`（行尾内缩分割线含在行高内），控制用 `IconAction`，完成勾只是状态不响应点击，用户请求的置顶箭头带无障碍描述。任务标题由 `taskTypeResource` 按请求取得，`CandidateConfiguration` 还按操作区分（书库同步为“元数据同步”，OneDrive 目录浏览为“加载目录”）。
- 书库页（`LibrariesPage`）与添加向导（`AddLibraryPage`）由 `LibraryListViewModel` 驱动：列表、当前书库和进行中的添加（`LibraryAddition`）都在状态库，进程重建与系统选择器／浏览器返回后按它恢复，向导步骤由 `LibraryListViewModel.step` 从添加记录和登录状态推出，不另存页面状态。操作串行执行，每次结束重读列表并按后端的 `LibraryAuthorization.access` 显示授权状态（不请求源）；`revision` 变化时其它页重读当前书库。完成添加前不改列表和当前选择；本地授权在没有书库或添加使用后才释放。删除经 `CacheMaintenance.previewLibrary` 预览并确认同一计划。当前书库行不设点击动作（而不是禁用的可点击容器），以免其中可用的重新授权／删除按钮落在禁用祖先之下。书库页的添加入口是顶栏右侧的加号（`LibrariesTopBar`）；书库页顶部的登录提示只在登录未处于已授权状态且正在浏览器登录、兑换或有问题时出现，已授权不显示任何提示（即使有暂时的刷新失败），各行自行显示登录状态；向导不设页内步骤横幅或底部按钮栏，`AddLibraryTopBar` 以“步骤名（n/3）”为标题，返回在第 1 步取消、之后经 `LibraryListViewModel.back` 回到上一步，第 3 步在顶栏右侧显示“完成”。类型选择用粗边框、图标和说明组成的选项块，与说明文字和 `ActionButton` 区分；OneDrive 目录选择（`DirectoryPage`）只出现在向导第 2 步：没有目录结果且没有进行中的加载时由 `OneDriveLibraryViewModel.browseIfEmpty` 自动加载根目录，失败不自动重试；加载中只显示静止的沙漏图标；目录名、刷新（`reload`，重新加载当前目录并保留返回路径）、返回上级和选择当前目录同在一行，任务完成时不显示状态文字，只显示等待原因和失败原因。
- 格式优先级保存在应用设置：`formatOrder` 把已保存顺序与导入中其余格式（按名称）合成显示列表，上移／下移后保存整个列表；`LibraryViewModel` 每次加载重新读取，用于默认格式与批量下载。关于页与许可证全文用 `PagedText` 按页宽测量并逐行分页，不滚动；第三方声明读取 `res/raw/third_party_notices.txt`，`LICENSE_TEXTS` 提供其许可证全文，`ThirdPartyNoticesTest` 核对它与 release 依赖锁一致。
