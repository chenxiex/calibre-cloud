# 步骤 06 人工验收指南

状态：本轮环境准备、真实云端只读自动检测和用户人工体验验收均已通过；设备 debug／测试包及专用目录已清理。以下操作保留为复验参考，不要求重复。实际证据与自动检查范围见 [第二阶段记录](phase-2.md)。人工只需准备个人 OneDrive 测试环境、完成登录，以及确认动画／墨水屏体验。下载、分页、重启、续传和错误恢复由 agent 验证，不再要求人工逐项点击或反复断网重连。

## 1. 一次性准备云端与登录

1. 在电脑解压 [测试 ZIP](../build/verification/step06/calibre-step06-acceptance-20261006.zip)，只将 `library-a` 上传至个人 OneDrive 的专用步骤 06 测试目录，等待上传完成。已有目录时确认它与 ZIP 中初始 `library-a` 一致；不要选择正式书库。
2. 本轮无需上传 `library-b`、`library-pause` 或 `updated-files`，也无需覆盖、改名或删除云端文件。`library-a` 包含 3 本书／4 个格式，首本 EPUB 为 51,734 字节。
3. 重新开展复验时，由 agent 安装独立 `Calibre Cloud Debug` 并停在第 2 页登录入口。自行登录个人账号；不要向 agent 提供密码或令牌。
4. 第 3 页选择云端 `library-a`，保持无线 ADB 连接，反馈“环境已准备好”。如果应用已经登录并选中了正确测试目录，可直接反馈。

随后 agent 使用应用内授权与生产后端进行只读云端验证：取得版本／大小、完整读取、非零偏移范围读取及字节校验，必要时在测试侧中断读取再恢复。云端请求只读取测试目录，不上传、删除、改名或修改元数据；允许独立 debug 应用写入自己的任务、暂存及副本。凭据留在设备，不输出下载链接。本轮环境准备和真实只读集成检测已完成，通过结果见第二阶段记录；无需重新登录、上传或重复执行。

无需人工计时暂停、强停或配合抓取断点。真实 OneDrive 的 Range 是否可用由实际返回和内容校验判定；完整下载成功不能替代范围读取成功。

## 2. 动画与墨水屏体验（已通过）

本轮用户已确认以下体验通过，设备环境已清理。复验时由 agent 准备第 8 页清单第一页和三条完整副本（两页），再执行：

1. 在第 7 页“书籍副本”和第 8 页“已下载文件”切换应用页、格式页与清单页，点击按钮并观察状态变化。底部按钮切应用页，页面内按钮切格式或清单。
2. 确认没有应用引入的过渡／加载动画。
3. 确认灰度下按钮、任务状态和选中提示可辨认，没有影响操作的残影。

反馈通过或失败；失败时说明页面、操作和现象。静态截图无法替代这项体验确认。

## 无需重复的项目与结束操作

本地实际断网重启已由用户确认通过，保留结论。断流、网络／授权失败后的断点保留与重试、暂停／取消、进程恢复、版本变化、源缺失及范围回退由接口故障注入和平台测试覆盖；不再列为每轮人工断网重连项目。只有发现真实设备网络行为与接口测试不一致等具体问题时，才安排相应定向实测。
