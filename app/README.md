# Android 工程

当前工程提供本地 SAF 目录授权入口、应用状态数据库、最小下载清单持久查询、应用完整副本读取和持久优先级任务队列。任务契约说明见 [任务模块](src/main/java/io/github/chenxiex/calibrecloud/tasks/AGENTS.md)。OneDrive 已接入个人账号浏览器授权和私有加密状态保存；真实登录验收状态见验证记录。队列与单执行协调器已实现，已注册本地快照导入和个人 OneDrive 浏览／快照导入处理器，提交后由 WorkManager 唤醒共享协调器，并提供任务状态与控制入口；Calibre 完整导入与动态布尔栏目配置已实现；本地复制／OneDrive 下载、完整副本发布、已下载格式更新及分页下载清单已实现；按格式移除、清元数据及其它书库缓存清理已接入；后台驱动、任务页和启动同步设置已接入；图书馆短按书籍经受控 URI 交给外部阅读器，底栏显示上次打开。

## 图书馆浏览

主界面自上而下为顶栏、内容框和底栏，各区之间有分割线；底栏“图书馆／更多”为图标加小字，所在页图标为实心。图书馆只读取最后一次有效导入和最小下载清单，不等待网络；每页数量按实测空间以数量优先计算：网格先放下尽可能多的不小于 96dp 的单元格、列表放下尽可能多的不小于 72dp 的行，再放大填满空间（PA6 竖屏网格 4×3、列表 6 行）。从左向右或从上向下滑动翻到上一页，反向翻到下一页；底部翻页行依次为首页、上一页、“当前页 / 总页数”、下一页、末页，首页／末页禁用对应方向，旋转或尺寸变化时保持当前首个可见项所在页。顶栏右侧为搜索、筛选和视图图标；视图菜单分组列出网格／列表、分类（不分类／丛书／标签／更多，“更多”弹出其它文本、枚举栏目）和当前层级适用的排序（文件夹层为名称，兜底文件夹始终最后），排序只列依据，选中依据旁的箭头表示方向，再点同一依据切换升／降序。切换选项不关闭菜单，再点视图图标或系统返回关闭；菜单和弹窗较长时同样分页并响应滑动。分类时只显示文件夹，进入文件夹后顶栏显示返回图标与文件夹名，系统返回恢复原分类和页码。网格封面缺图时显示标题，右上梯形斜幅为已读、右下为下载勾选；列表在封面右侧显示标题、作者、已读标签和默认格式大小，作者或大小未知时不显示占位文字。仅当前页可见书籍及文件夹代表书籍缺少封面时才低优先级入队加载，失败或离线保留文字占位。上次成功同步时间在“更多”的元数据页显示。

没有书库时提供“打开设置”，有书库但没有完整元数据时提供“同步元数据”和“已下载文件”入口，均进入“更多”中的对应临时页；这两种状态下搜索和筛选图标禁用。

筛选图标打开占用内容区的筛选面板，分组列出下载状态（已下载／未下载）、已读状态（已读／未读）和库内实际格式；下载状态和已读状态各为单选，再点已选项取消，格式可多选并取“或”，跨组取“且”。切换选项不关闭面板，再点筛选图标或系统返回关闭；有生效的筛选时图标右上角显示圆点。已读栏目未配置或失效时已读选项禁用并说明原因，不把整库当作未读。筛选在分类与文件夹间保持，变更后回到第一页。

搜索图标进入独立搜索页：顶栏为返回图标、圆角输入框（进入时自动聚焦）、筛选和视图图标。输入为空时，内容区上方是字段徽标（全部、标题、作者、丛书、标签、简介及可用的文本／枚举栏目），下方是分页的搜索历史与“清除”；选中特定字段后输入框内显示字段名；输入框有文字时右侧有清空图标，点击后清空并回到历史。只有按键盘搜索键才执行查询并写入当前书库的历史，点历史项重新执行。搜索覆盖整个书库、保留筛选，结果平铺为书籍，复用网格／列表、书籍排序与翻页，视图菜单不含分类；视图、排序和筛选初始沿用图书馆，在搜索页的修改不影响图书馆。返回图标或系统返回回到进入前的分类、文件夹和页码。历史按书库保存在应用状态库，清除元数据保留历史，“清除”只删当前书库的历史。UI 约定见 [界面约束](src/main/java/io/github/chenxiex/calibrecloud/ui/AGENTS.md)。

下文十三个显式页面是第二阶段临时验证入口，现位于“更多”，后续步骤逐步由正式页面替代。

## 外部阅读器打开

短按书籍打开当前默认格式：有完整副本时直接交给系统，否则高优先级排队下载／复制。只有本应用仍在前台、用户仍停留在当前页面并等待同一本书时，下载完成后才自动打开；退到后台、切换页面或书库、点击另一本书后只继续下载。没有可处理该格式的应用或系统调用失败时以感叹号和通知说明，已下载的副本保留。

阅读器收到 `content://<applicationId>.books/<书名-书籍ID.后缀>?copy=<书库>:<文件代次>` 和格式 MIME，只获得该 URI 的临时只读权限；provider 只提供下载清单中仍发布的完整代次，查询返回与路径相同的显示名“书名-书籍ID.后缀名”（空标题为“未命名书籍-书籍ID.后缀名”）和大小。阅读器会以 URI 路径（如 PA6 的汉王阅读器，书架显示 `_书名-书籍ID`）或显示名（如 KOReader）作导入文件名，同名书因 ID 不同而不会互相覆盖。系统调用成功后，底栏右侧显示当前书库上次打开的封面（缺图时为标题），点击按记录的格式再次打开；记录不表示阅读进度，清除元数据保留它，切换书库只显示该书库的记录。书籍有未结束的下载时（包括打开后退到后台），右下角（列表为行右侧）显示外缘带进度弧的叉号，点击即取消该下载任务；已下载的书显示圆形勾。下载需要处理（如等待网络、登录或授权）或打开失败时该处改为感叹号，原因以系统通知发送，有对应设置页时点击通知进入；失败后点击书籍即重试。不提供单本“选择格式”，其它格式通过格式筛选或优先级打开。实现约束见[文件提供约束](src/main/java/io/github/chenxiex/calibrecloud/files/AGENTS.md)与[界面约束](src/main/java/io/github/chenxiex/calibrecloud/ui/AGENTS.md)。

## 本地目录授权

点击“选择／重新授权目录”，在系统文件选择器中选择设备本地存储或 SD 卡目录。当前支持系统本地存储提供方；云端和未知提供方会被拒绝。取消重选保留原选择，重启后恢复持久授权；只读或失效时提示重新授权。

目录选择成功后保存当前候选位置与选择代号；取消保留原配置，重选保留旧书库绑定和副本。最小清单和副本读取已接入同一个应用状态库，可从书籍副本页显式传输，并在已下载文件页查看。

目录授权只表示平台权限已保存。点击“验证／同步元数据”才会提交高优先级候选任务，通过 SAF 只读获取根目录 `metadata.db`，检查内容版本、事务日志、SQLite 完整性与 Calibre 结构，再完整导入并激活书库。源发生变化、存在非空事务日志、目录缺失、权限失效或结构不兼容时显示明确错误，保留之前有效的导入。
加载可以暂停、继续、取消或失败后重试；继续与进程恢复均重新获取源，不复用未验证的暂存。取消后使用“验证／同步元数据”创建当前选择的新请求。未完成任务由持久后台队列按平台条件恢复；新自动同步由默认关闭的启动设置决定。只读授权也可加载，但不意味着具有安全写回能力。通过“上一页／下一页”查看授权入口。

## 导入与栏目配置

当前入口为十三个显式页面：本地授权／同步、OneDrive 授权、目录选择、OneDrive 同步、当前书库统计、已读栏目设置、书籍副本、已下载文件、按需封面、缓存清理、任务列表、启动同步设置、后台与通知状态。同步成功后显示书籍／格式数量和上次成功同步时间；重新打开应用先显示私有导入，不等待网络；启动同步设置开启时在后台入队同步。再次选择已导入的位置可复用其最后有效缓存，新验证发现书库 UUID 或原数字 ID 对应的书籍 UUID 冲突时隔离为新的书库身份，旧缓存保持独立。

已读栏目页只列出导入发现的布尔栏目，按显示名称与动态 lookup 名选择并保存。未配置或栏目改名、删除、类型变化时明确显示配置问题；源空／否在有效配置下为未读，是为已读。当前没有源写回按钮，也不保存本地阅读状态覆盖。已读筛选见上文“图书馆浏览”。解析和发布契约见 [元数据模块](src/main/java/io/github/chenxiex/calibrecloud/metadata/AGENTS.md)。

## 书籍副本与下载清单

第 7 页按书籍／格式显式分页，选择固定格式后点击“复制当前格式”或“下载当前格式”。普通页面恢复与副本读取只访问私有数据；缺少副本不会自动读取源或下载。传输前按源文件大小检查可用空间（本地使用 SAF 文档大小），任务页显示已传输字节与总量。当前任务可暂停、继续、取消及失败后重试；暂停及传输中断保留已同步到磁盘的暂存前缀；继续／进程恢复时核对源版本与前缀散列，本地可寻址 SAF 使用直接定位，OneDrive 使用经严格校验的范围响应接续。源版本变化、断点损坏或提供方不支持范围读取时重新下载；固定版本任务发生冲突则拒绝。取消会清理暂存。重开页面只查询私有队列；后台执行器恢复中断任务时重新核验源与暂存。“立即执行”可请求后台立即唤醒队列，网络等待及退避由平台调度继续。

传输完成并通过长度／内容与源版本复核后发布不可变新文件代次；更新失败保留完整旧副本，已打开的旧句柄可继续读旧字节。每次完整元数据导入只为最小下载清单中的格式入队低优先级版本检查，确认变化才追加单格式更新，不自动下载其他格式。授权或网络失败保留已有源状态；明确缺失时保留副本并显示源已不可用。

第 8 页从独立最小清单分页显示保存标题、格式、可知大小、源确认状态和实际副本可用状态，每页一条。点击“移除此格式副本”仅清理显示格式，也可选择“移除此书全部格式”；确认前显示冻结格式范围、完整副本数量和字节数，同时停止范围内未完成的副本任务并清理对应暂存。其它格式保持可用，清元数据后仍可从此页查看和移除已有副本。图书馆中的外部打开见上文“外部阅读器打开”。生产传输与发布契约见 [任务副本实现](src/main/java/io/github/chenxiex/calibrecloud/tasks/copies/FormatCopyTaskHandler.kt)，实际证据及待共同验收项目见 [第二阶段记录](verification/phase-2.md) 和 [步骤 06 设备指南](verification/step-06-device-guide.md)。

## 按需封面

当前第 9 页为静态分页封面入口，一页显示一本书。仅进入该页或切换可见书籍时，缺失封面才通过持久队列低优先加载；已有缓存直接读取，不访问源。OneDrive 优先使用该书籍 `cover.jpg` 图片的缩略图，无可用缩略图时读取封面原图并缩放。本地通过 SAF 后端读取同一图片；不为封面复制书籍格式。无图、离线或失败时保留标题占位，已有完整旧图不因失败删除，可显式继续／重试。封面缓存独立限额管理，书籍副本不会因此被淘汰。

实现边界见[封面缓存约束](src/main/java/io/github/chenxiex/calibrecloud/storage/covers/AGENTS.md)，本步共同验收见[步骤 07 指南](verification/step-07-device-guide.md)及[第二阶段记录](verification/phase-2.md)。图书馆页面的可见封面见上文“图书馆浏览”。


## 缓存清理

第 10 页提供“清除当前元数据缓存”和“清除所有其它书库缓存”。先查看动作范围、书库数、完整副本数与应用缓存字节数，逐库显式翻页核对身份，再确认或取消；执行后显示完成或未完成结果。清理只操作应用私有数据，不要求旧源书库可访问。

清除当前元数据会移除数据库快照、完整索引和封面，并停止既有普通加载任务；书籍副本、下载清单及已读栏目配置保留。当前书库统计和完整书籍／封面入口会显示元数据尚未加载，下载清单的源状态回到“尚未确认”；需要重新加载时，到相应后端页显式“验证／同步元数据”。清除其它书库缓存覆盖确认范围内所有非当前书库的副本、索引、封面和相关暂存，保留当前书库和保护资料。范围协调与恢复契约见[存储约束](src/main/java/io/github/chenxiex/calibrecloud/storage/AGENTS.md)，实际验证与未完成验收见[第二阶段记录](verification/phase-2.md)和[步骤 08 共同验收](verification/step-08-device-guide.md)。

## 后台任务与启动同步

第 11 页按持久状态显示任务来源、实际优先级、等待原因、阶段及可知进度；仅因调度顺序等待时显示“排队”及序号，网络、限流、登录、目录授权等外部条件才显示具体原因。需要重新登录或目录授权失效的任务进入等待，重新登录或重新选择同一目录后自动继续；长列表显式分页，仅展示当前阶段支持的控制。进度默认最多每两秒刷新一次，状态变化可立即显示；未知总量显示文字。应用退到后台后任务可继续，系统中断或重启后通过 WorkManager 恢复，实际执行仍由应用队列决定优先级与顺序。

第 12 页提供“立即同步元数据”和默认关闭的“启动应用时自动同步”。开启后，每个进程首次用户打开主界面且已有书库配置时入队一次低优先级同步；重建 Activity、普通切换前后台和返回阅读器不重复触发。手动同步始终高优先级，复用并提升等价未完成自动任务。清元数据保留该设置，手动重新加载始终可用；后台恢复启动进程不会创建新启动同步。

第 13 页显示通知与系统后台限制，并提供通知授权及重新唤醒入口。执行期间使用静态后台通知；拒绝通知权限、系统省电或调度限制会影响通知显示或后台机会，页面保留实际任务和等待状态。后台运行不保证立即开始、精确定时、强行停止后继续或绕过平台限制；强行停止后重新打开应用可请求恢复。首版不创建周期同步任务。步骤 09 的真实系统证据与尚未完成项见[第二阶段记录](verification/phase-2.md)，必要准备及人工体验见[共同验收指南](verification/step-09-device-guide.md)。

## 构建

使用 JDK 21、Android SDK 36 和 Build Tools 36.0.0；最低支持 Android 11 / API 30。环境与设备连接见 [开发容器说明](../.github/.devcontainer/README.md)。

在项目根目录运行：

```bash
./gradlew --version
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease :app:assembleDebugAndroidTest :app:lintDebug :app:lintRelease
```

默认资源参数见 [gradle.properties](../gradle.properties)：worker 上限 4、JVM 可用处理器数 4、堆上限 2 GiB。临时降低资源占用：

```bash
./gradlew :app:assembleDebug --max-workers=1 '-Dorg.gradle.jvmargs=-Xmx2g -XX:ActiveProcessorCount=1 -Dfile.encoding=UTF-8'
```

依赖版本见 [版本目录](../gradle/libs.versions.toml)，实际解析版本见 [依赖锁](gradle.lockfile)。

## OneDrive 配置

工程读取根目录被忽略的 `local.properties`，保留 `sdk.dir` 等已有属性。微软注册步骤与无凭据模板见 [OneDrive 应用注册](../README.md#onedrive-应用注册)。三项属性全部填写后才启用配置：

| 属性 | 用途 |
| --- | --- |
| `onedrive.clientId` | 两变体共用的开发者注册标识 |
| `onedrive.redirectUri` | release 完整回调 URI |
| `onedrive.debugRedirectUri` | debug 完整回调 URI |

正式版和 debug 版推荐使用各自独立的小写自定义 scheme，并与微软注册的 URI 完全一致；不需要 client secret。

缺少任一项时仍可构建和使用本地授权，OneDrive 页面显示配置指引。完整配置非法或回调范围重叠时，按构建错误中指出的属性修正。配置有效后点击“登录／重新登录”，在系统浏览器中使用个人微软账号授权。返回应用后显示授权结果；返回时未完成授权，可点击“取消登录”再重试。请求十分钟后失效。已授权时可显式刷新授权；凭据恢复失败会要求重新登录。

“个人 OneDrive 已授权”只表示 OAuth 授权完成。通过页面按钮进入目录页，点击“浏览／切换到 OneDrive”切换当前候选后端（旧书库缓存保留），浏览本人云盘；进入目录时一次完整加载子项目（Graph 返回分页时在同一任务中取完），随后上一页／下一页仅切换本地列表。当前入口是第二阶段临时验证 UI，目录页每页三个目录用于验证分页；最终目录选择界面在第三阶段实现，不固定为三个目录。使用返回上层导航切换目录。在专用书库目录内点击“选择当前目录为书库”，再到第 4 页“OneDrive 任务与快照”显式“验证／同步元数据”。快照在同一任务中通过 Calibre 结构验证并完整导入后激活书库，结果见当前书库页。该页提供当前阶段支持的暂停、取消、继续及重试；限流退避和网络等待由后台调度恢复。重新打开目录页面只读私有配置和任务；主界面冷启动的自动同步遵循启动开关。

源路径仅在选定根内逐级解析，只读请求检查文件内容 cTag 与事务日志；无法确认一致性时保留旧快照并提示错误。网络／授权失败不会把源标为删除；预签名内容链接只用于当前传输。文件后端约束见 [OneDrive 后端](src/main/java/io/github/chenxiex/calibrecloud/storage/onedrive/AGENTS.md)，本步证据与待验项目见 [第二阶段记录](verification/phase-2.md)。令牌和进行中的登录请求通过 Android Keystore 加密保存，重启可恢复，不进入书籍 provider、普通缓存或备份。

```bash
python3 scripts/verify-oauth-config.py
```

结果与日志保存在被忽略的 `.oauth-verification/` 中。配置校验、回调匹配和授权实现约束见 [授权模块 AGENTS.md](src/main/java/io/github/chenxiex/calibrecloud/auth/AGENTS.md)。
