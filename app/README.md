# Android 工程

当前工程提供本地 SAF 目录授权入口、应用状态数据库、最小下载清单持久查询、应用完整副本读取和持久优先级任务队列。任务契约说明见 [任务模块](src/main/java/io/github/chenxiex/calibrecloud/tasks/AGENTS.md)。OneDrive 已接入个人账号浏览器授权和私有加密状态保存；真实登录验收状态见验证记录。队列与单执行协调器已实现，已注册本地快照导入和个人 OneDrive 浏览／快照导入处理器，提交后由 WorkManager 唤醒共享协调器，并提供任务状态与控制入口；Calibre 完整导入与动态布尔栏目配置已实现；本地复制／OneDrive 下载、完整副本发布、已下载格式更新及分页下载清单已实现；按格式移除、清元数据及其它书库缓存清理已接入；后台驱动、任务页和启动同步设置已接入；图书馆短按书籍经受控 URI 交给外部阅读器，底栏显示上次打开；“更多”按小标题组织元数据、存储与缓存、任务、设置和关于。

## 图书馆浏览

主界面自上而下为顶栏、内容框和底栏，各区之间有分割线；底栏依次为“图书馆”、继续阅读和“更多”三个等宽按钮，均为图标加小字，所在页图标为实心。图书馆只读取最后一次有效导入和最小下载清单，不等待网络；每页数量按实测空间以数量优先计算：网格先放下尽可能多的不小于 96dp 的单元格、列表放下尽可能多的不小于 72dp 的行，再放大填满空间（PA6 竖屏网格 4×3、列表 6 行）。从左向右或从上向下滑动翻到上一页，反向翻到下一页；底部翻页行依次为首页、上一页、“当前页 / 总页数”、下一页、末页，首页／末页禁用对应方向，旋转或尺寸变化时保持当前首个可见项所在页。顶栏右侧为搜索、筛选和视图图标；视图菜单分组列出网格／列表、分类（不分类／丛书／标签／更多，“更多”弹出其它文本、枚举栏目）和当前层级适用的排序（文件夹层为名称，兜底文件夹始终最后），排序只列依据，选中依据旁的箭头表示方向，再点同一依据切换升／降序。切换选项不关闭菜单，再点视图图标或系统返回关闭；菜单和弹窗较长时同样分页并响应滑动。分类时只显示文件夹，进入文件夹后顶栏显示返回图标与文件夹名，系统返回恢复原分类和页码。网格封面缺图时显示标题，右上梯形斜幅为已读、右下为下载勾选；列表在封面右侧显示标题、作者、已读标签和默认格式大小，作者或大小未知时不显示占位文字。仅当前页可见书籍及文件夹代表书籍缺少封面时才低优先级入队加载，失败或离线保留文字占位。上次成功同步时间在“更多”的元数据分组显示。

没有当前书库时提供“打开设置”（进入“更多”的书库页），有书库但没有完整元数据时提供“同步元数据”（进入“更多”菜单）和“已下载文件”入口，若同步已在进行（如添加书库后的首次同步）则改为说明正在同步或等待，并提供“查看同步状态”；这两种状态下搜索和筛选图标禁用。

筛选图标打开占用内容区的筛选面板，分组列出下载状态（已下载／未下载）、已读状态（已读／未读）和库内实际格式；下载状态和已读状态各为单选，再点已选项取消，格式可多选并取“或”，跨组取“且”。切换选项不关闭面板，再点筛选图标或系统返回关闭；有生效的筛选时图标右上角显示圆点。已读栏目未配置或失效时已读选项禁用并说明原因，不把整库当作未读。筛选在分类与文件夹间保持，变更后回到第一页。

搜索图标进入独立搜索页：顶栏为返回图标、圆角输入框（进入时自动聚焦）、筛选和视图图标。输入为空时，内容区上方是字段徽标（全部、标题、作者、丛书、标签、简介及可用的文本／枚举栏目），下方是分页的搜索历史与“清除”；选中特定字段后输入框内显示字段名；输入框有文字时右侧有清空图标，点击后清空并回到历史。只有按键盘搜索键才执行查询并写入当前书库的历史，点历史项重新执行。搜索覆盖整个书库、保留筛选，结果平铺为书籍，复用网格／列表、书籍排序与翻页，视图菜单不含分类；视图、排序和筛选初始沿用图书馆，在搜索页的修改不影响图书馆。返回图标或系统返回回到进入前的分类、文件夹和页码。历史按书库保存在应用状态库，清除元数据保留历史，“清除”只删当前书库的历史。UI 约定见 [界面约束](src/main/java/io/github/chenxiex/calibrecloud/ui/AGENTS.md)。

## 外部阅读器打开

短按书籍打开当前默认格式：有完整副本时直接交给系统，否则高优先级排队下载／复制。只有本应用仍在前台、用户仍停留在当前页面并等待同一本书时，下载完成后才自动打开；退到后台、切换页面或书库、点击另一本书后只继续下载。没有可处理该格式的应用或系统调用失败时以感叹号和通知说明，已下载的副本保留。

阅读器收到 `content://<applicationId>.books/<书名-书籍ID.后缀>?copy=<书库>:<文件代次>` 和格式 MIME，只获得该 URI 的临时只读权限；provider 只提供下载清单中仍发布的完整代次，查询返回与路径相同的显示名“书名-书籍ID.后缀名”（空标题为“未命名书籍-书籍ID.后缀名”）和大小。阅读器会以 URI 路径（如 PA6 的汉王阅读器，书架显示 `_书名-书籍ID`）或显示名（如 KOReader）作导入文件名，同名书因 ID 不同而不会互相覆盖；不同书库中 ID 与书名都相同的书（多为同一书库的不同副本）在这类阅读器中视为同一本，后打开的覆盖先导入的文件并共用阅读进度（Q71）。要求真实文件路径的阅读器（如 PA6 自带的汉王 PDF 阅读器）不能打开受控 URI，PDF 可用 KOReader。系统调用成功后，底栏中间出现继续阅读按钮：打开的书图标，下方为当前书库上次打开的书名（单行，过长以省略号截断），点击按记录的格式再次打开；没有记录时隐藏，“图书馆”“更多”平分底栏；记录不表示阅读进度，清除元数据保留它，切换书库只显示该书库的记录。书籍有未结束的下载时（包括打开后退到后台），右下角（列表为行右侧）显示外缘带进度弧的叉号，点击即取消该下载任务；已下载的书显示圆形勾。下载需要处理（如等待网络、登录或授权）或打开失败时该处改为感叹号，原因以系统通知发送，有对应设置页时点击通知进入；失败后点击书籍即重试。不提供单本“选择格式”，其它格式通过格式筛选或优先级打开。实现约束见[文件提供约束](src/main/java/io/github/chenxiex/calibrecloud/files/AGENTS.md)与[界面约束](src/main/java/io/github/chenxiex/calibrecloud/ui/AGENTS.md)。

## 更多页

“更多”顶栏左侧为标题，右侧的搜索图标只按名称过滤本页菜单（空格分隔的每个词都需出现），不检索书库。菜单按小标题分组，较长时分页并响应滑动：

- 元数据：先说明书库状态——尚未选择书库（另有“添加或选择书库”）、尚无完整元数据，或上次成功同步时间；同步排队、等待、暂停或失败时再显示状态和原因。“立即同步元数据”以高优先级提交，复用并提升等价的未完成同步；“清除元数据缓存”进入确认页。
- 存储与缓存：“已下载文件”“清除所有其它书库缓存”。
- 任务：“任务队列”“后台与通知”。
- 设置：“书库”、“启动应用时自动同步”（打勾为开启，默认关闭）、“格式优先级”、“已读栏目”。
- 关于：“关于本应用”。

子页顶栏左侧为返回图标，系统返回回到上一级。图书馆和通知的入口直接打开对应子页。页面代码约定见[界面约束](src/main/java/io/github/chenxiex/calibrecloud/ui/AGENTS.md)。

### 书库

书库页列出添加过的书库，每行为目录名及“后端 · 授权状态”（本地目录：已授权、只读授权或目录授权已失效；OneDrive：已登录或需要登录此书库的账号），当前书库左侧为选中的单选圆点、名称加粗，较多时分页。点击另一行即切换当前书库，不再确认；原书库的缓存保留，切回时沿用，可在“清除所有其它书库缓存”中清理而保留列表项。授权失效的行显示“重新授权”：本地目录打开系统选择器，只接受同一目录；OneDrive 打开浏览器登录并让你选择账号。每行右侧的移除图标先显示确认页（该书库可释放的应用空间与副本数，移除当前书库时另有提示），确认后清除该书库在应用中的全部数据（副本、下载清单、索引、封面、未完成任务、搜索历史、上次打开和已读栏目设置），不动源文件；移除当前书库后没有当前书库，不自动切换。

顶栏右侧的加号进入“添加书库”三步向导。向导的顶栏标题显示步骤名和进度（如“选择位置类型（1/3）”）；顶栏返回与系统返回在第一步取消添加、之后回到上一步；完成前书库列表和当前书库都不变：

1. 选择位置类型：“本地目录”和“OneDrive”是带图标和说明的粗边框选项块，点击即进入下一步；OneDrive 未配置时不可选并说明原因（见下文“OneDrive 配置”）。
2. 授权并选择目录：本地目录直接打开系统选择器，选择设备本地存储或 SD 卡上的书库目录（云端和未知提供方会被拒绝），取消后可点“选择目录”重试。OneDrive 未登录时先“登录”；已登录时可“使用当前账号”或“登录其他账号”（只保存一个登录，换号后原账号的书库需要重新登录）。登录后自动加载根目录（加载中显示沙漏图标，失败时显示原因和“重新加载”），然后浏览目录：每进入一个目录由一个任务完整加载其子目录，翻页只切换本地列表，每页目录数按可用空间决定；目录栏右侧的圆形箭头重新加载当前目录（如刚上传了书库），向上箭头逐级返回上层，进入书库目录后点勾选择当前目录。
3. 确认：显示类型和目录名（已在列表中的书库另有说明）。点击顶栏右侧的“完成”后加入列表、设为当前书库，以高优先级同步元数据并回到图书馆。

同步通过 SAF 或 Graph 只读获取根目录 `metadata.db`，检查内容版本、事务日志、SQLite 完整性与 Calibre 结构，再完整导入并激活书库。源发生变化、存在非空事务日志、目录缺失、权限失效或结构不兼容时显示明确错误，保留之前有效的导入。再次添加或切回已导入的位置复用其最后有效缓存；书库 UUID 或书籍 UUID 冲突时隔离为新的书库身份。只读授权也可同步，但不意味着具有安全写回能力。

同步可在任务队列中暂停、继续、取消或失败后重试；继续与进程恢复均重新获取源，不复用未验证的暂存。

### 格式优先级与已读栏目

格式优先级页按顺序列出已保存的格式和当前导入中其余格式（按名称排在后面），初始为 EPUB 优先；每行的上移／下移按钮移动一位并立即保存。打开与下载时先按此顺序选已下载的格式，没有再按此顺序选源格式；设置全局保存，清理缓存不影响它。

已读栏目页只列出导入发现的布尔栏目，按显示名称与动态 lookup 名选择并保存在本应用；未配置或栏目改名、删除、类型变化时明确显示配置问题。源空／否在有效配置下为未读，是为已读。当前没有源写回，也不保存本地阅读状态覆盖。解析和发布契约见 [元数据模块](src/main/java/io/github/chenxiex/calibrecloud/metadata/AGENTS.md)。

### 已下载文件与副本传输

已下载文件页从独立的最小清单分页显示当前书库的完整副本：标题、格式、可知大小、源确认状态，副本缺失或损坏时另行说明；每页条数按可用空间决定。可打开副本，或“移除此格式”／“移除全部格式”；确认前显示冻结的格式范围、副本数量和大小，确认后同时停止范围内未完成的副本任务并清理暂存，其它格式保持可用。清除元数据后仍可在此打开和移除已有副本。

书籍副本由图书馆打开或批量下载提交。普通页面恢复与副本读取只访问私有数据，缺少副本不会自动读取源。传输前按源文件大小检查可用空间（本地使用 SAF 文档大小），任务队列显示传输百分比；暂停和中断保留已同步到磁盘的暂存前缀，继续或进程恢复时核对源版本与前缀散列，本地可寻址 SAF 直接定位，OneDrive 使用经严格校验的范围响应接续；源版本变化、断点损坏或提供方不支持范围读取时重新下载。传输完成并通过长度／内容与源版本复核后发布不可变新文件代次；更新失败保留完整旧副本，已打开的旧句柄可继续读旧字节。每次完整导入只为已下载格式检查版本，确认变化才追加单格式更新。授权或网络失败保留已有源状态；明确缺失时保留副本并显示源已不可用。生产传输与发布契约见 [任务副本实现](src/main/java/io/github/chenxiex/calibrecloud/tasks/copies/FormatCopyTaskHandler.kt)。

封面只为图书馆当前页缺失的封面低优先级加载，每页一个批次；翻到另一页并为它提交批次时，上一页批次不再开始新封面，没有新批次（新页封面已缓存、离开图书馆或进入搜索）时上一页批次继续完成：OneDrive 优先使用书籍 `cover.jpg` 的缩略图，否则读取原图并缩放；本地经 SAF 读取同一图片，不为封面复制书籍格式。无图、离线或失败时保留标题占位。封面缓存独立限额管理，见[封面缓存约束](src/main/java/io/github/chenxiex/calibrecloud/storage/covers/AGENTS.md)。

### 缓存清理

“清除元数据缓存”和“清除所有其它书库缓存”进入页面即计算范围（书库数、书籍副本数和可释放的应用空间），确认后执行同一范围，取消则不做任何改动；清理只操作应用私有数据，不要求旧源书库可访问。清除当前元数据会移除数据库快照、完整索引和封面并停止既有普通加载任务；书籍副本、下载清单、配置、搜索历史和上次打开保留，下载清单的源状态回到“尚未确认”，需要时再立即同步。清除其它书库缓存覆盖所有非当前书库的副本、索引、封面和相关暂存，保留当前书库和保护资料。范围协调与恢复契约见[存储约束](src/main/java/io/github/chenxiex/calibrecloud/storage/AGENTS.md)。

### 任务与后台

任务队列分“进行中”和“已完成”（含失败和取消，最近提交的在最前）两个标签，右侧可筛选“全部”“用户请求”“自动任务”；每页按可用空间显示多行扁平任务：粗体任务类型下方一行小字，用户请求（含被提升的任务）前有置顶箭头，仅因调度顺序等待时显示“排队 #N”，网络、限流、登录、目录授权等外部条件显示具体原因，执行中显示阶段与可知的百分比进度，失败显示阶段和原因。行右侧只显示当前状态支持的图标：暂停／继续、取消、失败后重试，成功完成显示勾。进度默认最多每两秒刷新一次，状态变化立即显示。已结束的任务只保留最近提交的 50 条，更早的连同遗留暂存自动清理；仍被其它任务依赖或保留恢复资料的不清理。打开任务队列时先把已结束进程遗留的执行记录恢复为排队，不访问源。需要重新登录或目录授权失效的任务进入等待，重新登录或重新选择同一目录后自动继续。

开启“启动应用时自动同步”后，每个进程首次用户打开主界面且已有书库配置时入队一次低优先级同步；重建 Activity、普通切换前后台和返回阅读器不重复触发，后台恢复启动进程也不会创建。清元数据保留该设置，首版不创建周期同步任务。

后台与通知页显示通知与系统后台限制，并提供通知授权及重新唤醒入口。执行期间使用静态后台通知；后台运行不保证立即开始、精确定时、强行停止后继续或绕过平台限制。真实系统证据见[第二阶段记录](verification/phase-2.md)。

```bash
./gradlew --version
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease :app:assembleDebugAndroidTest :app:lintDebug :app:lintRelease
```

默认资源参数见 [gradle.properties](../gradle.properties)：worker 上限 4、JVM 可用处理器数 4、堆上限 2 GiB。临时降低资源占用：

```bash

```

## 构建产物

| 变体 | application ID | 名称 | APK |
| --- | --- | --- | --- |
| release | `io.github.chenxiex.calibrecloud` | Calibre Cloud | 已配置签名时为 `build/outputs/apk/release/app-release.apk`，否则为 `app-release-unsigned.apk` |
| debug | `io.github.chenxiex.calibrecloud.debug` | Calibre Cloud Debug | `build/outputs/apk/debug/app-debug.apk` |
| debug AndroidTest | `io.github.chenxiex.calibrecloud.debug.test` | 测试包 | `build/outputs/apk/androidTest/debug/app-debug-androidTest.apk` |

未配置签名时 release 产物不签名。debug 使用独立包名、应用数据目录、provider authority 和 OAuth 回调，可与正式版共存；设备验证流程只安装、操作和卸载 debug 与测试包。

## 发布签名

覆盖升级要求每个版本都使用同一密钥签名，且 `versionCode` 递增；签名密钥丢失或更换后只能卸载重装，应用数据随之清除。应用状态数据库也拒绝降级。

1. 生成发布密钥库（密码按提示输入）：

    ```bash
    keytool -genkeypair -v -keystore calibre-cloud-release.jks -alias calibre-cloud -keyalg RSA -keysize 4096 -validity 36500
    ```

    密钥库与密码自行异地备份，不提交到仓库（`*.jks`、`*.keystore` 已被 Git 忽略）。只保存在开发容器内的文件可能随容器或卷重建丢失。

2. 在根目录 `local.properties` 中添加以下四项。追加前确认文件末尾已有换行；`release.storeFile` 可用绝对路径或相对项目根目录的路径。

    ```properties
    release.storeFile=calibre-cloud-release.jks
    release.storePassword=<密钥库密码>
    release.keyAlias=calibre-cloud
    release.keyPassword=<密钥密码>
    ```

3. 构建并核对签名证书：

    ```bash
    ./gradlew :app:assembleRelease
    $ANDROID_HOME/build-tools/36.0.0/apksigner verify --print-certs app/build/outputs/apk/release/app-release.apk
    ```

四项都不填时 release 保持未签名；只填部分或密钥库文件不存在时构建失败并指出对应属性。发布新版本前在 [app/build.gradle.kts](build.gradle.kts) 中递增 `versionCode`，并按需更新 `versionName`。

## OneDrive 配置

工程读取根目录被忽略的 `local.properties`，保留 `sdk.dir` 等已有属性。微软注册步骤与无凭据模板见 [OneDrive 应用注册](../README.md#onedrive-应用注册)。三项属性全部填写后才启用配置：

| 属性 | 用途 |
| --- | --- |
| `onedrive.clientId` | 两变体共用的开发者注册标识 |
| `onedrive.redirectUri` | release 完整回调 URI |
| `onedrive.debugRedirectUri` | debug 完整回调 URI |

正式版和 debug 版推荐使用各自独立的小写自定义 scheme，并与微软注册的 URI 完全一致；不需要 client secret。

缺少任一项时仍可构建和使用本地目录，“更多 → 书库 → 添加书库”中的 OneDrive 选项不可选并说明原因。完整配置非法或回调范围重叠时，按构建错误中指出的属性修正。配置有效后在添加向导中点击“登录”，在系统浏览器中使用个人微软账号授权。返回应用后显示授权结果；返回时未完成授权，可点击“取消登录”再重试。请求十分钟后失效。凭据恢复失败会要求重新登录。

登录成功后不单独显示“已授权”提示，向导直接进入目录选择，书库页各行显示各自的登录状态；书库页只在从某行重新登录的过程中或失败时显示登录提示。目录选择与同步见上文“书库”。进入目录时一次完整加载子项目（Graph 返回分页时在同一任务中取完），随后翻页只切换本地列表；限流退避和网络等待由后台调度恢复。主界面冷启动的自动同步遵循启动开关。

源路径仅在选定根内逐级解析，只读请求检查文件内容 cTag 与事务日志；无法确认一致性时保留旧快照并提示错误。网络／授权失败不会把源标为删除；预签名内容链接只用于当前传输。文件后端约束见 [OneDrive 后端](src/main/java/io/github/chenxiex/calibrecloud/storage/onedrive/AGENTS.md)，本步证据与待验项目见 [第二阶段记录](verification/phase-2.md)。令牌和进行中的登录请求通过 Android Keystore 加密保存，重启可恢复，不进入书籍 provider、普通缓存或备份。

从根目录验证配置矩阵：

```bash
python3 scripts/verify-oauth-config.py
```

结果与日志保存在被忽略的 `.oauth-verification/` 中。配置校验、回调匹配和授权实现约束见 [授权模块 AGENTS.md](src/main/java/io/github/chenxiex/calibrecloud/auth/AGENTS.md)。

构建结果、产物检查及未完成的验收见 [第一阶段验证记录](verification/phase-1.md)。应用状态与最小清单的实现及验证见 [第二阶段验证记录](verification/phase-2.md) 和 [状态库约束](src/main/java/io/github/chenxiex/calibrecloud/state/AGENTS.md)。面向 agent 的模块开发约束见 [AGENTS.md](AGENTS.md)。
