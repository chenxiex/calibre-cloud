# Android 真机操作

遵循仓库和 `app/AGENTS.md` 的测试范围及清理要求。本技能只复用操作，不扩大源书库、账号或设备设置的授权，也不替代真实后端证据或人工墨水屏体验验收。

## 操作顺序

1. 优先运行已有 AndroidTest、ADB 查询和数据校验；只有验收需要经过 UI 的路径才导航。不要为了截图重演已通过且未受变更影响的检查。
2. 用 [helper](scripts/android_ui.py) 按资源 ID、文字或 content-desc 定位。先用有限的 `inspect` 查询确认选择器，再把连续动作写成带后置条件的 JSON `flow`；一条命令执行整段流程，避免每次点击都往返主 agent。命令和流程格式见 [操作参考](references/usage.md)。
3. 所有点击必须有明确包名、页面前置及后置条件，不允许用索引选择同名按钮。helper 在点击前两次核对焦点包、页面及目标，条件变化就停止；它不能保证检测与点击原子化，执行时用户应避免同时操作设备。匹配不唯一、覆盖弹窗、按钮不可用或后置条件超时就停止；结果未知的点击不得自动重试。
4. 坐标备用只供主 agent 在实际需要时核对并执行；轻量子 agent 只能报告候选，不能执行 `coordinate`、裸 ADB 点击或其它绕过 helper 的动作。不得照搬其他设备坐标；没有实测记录就使用元素定位。只有 XML 无法提供定位或需要视觉证据时才截图。

## 委派与证据

机械流程或异常页面值得隔离时，委派给仓库角色 `android_device`，一次覆盖完整流程。同一 serial 的执行权只交给一个 agent；主 agent 在它完成前不再操作设备。helper 的设备锁只保护使用该 helper 的进程，不能保护其它裸 ADB 点击。

主 agent 在委派前核对流程与操作范围，提供最小清单：唯一 serial、debug 包、允许经过的系统页面包名、测试目录完整位置、有限目标、已核对 flow 文件及每步前置／后置条件、产物路径。轻量子 agent 只执行该文件，必须使用 `flow --elements-only`，不能自己编写／修改流程或放宽条件；helper 在执行任何动作前拒绝该模式中的坐标步骤。资料缺失时只进行限定只读定位，将结果交回主 agent 补齐；不靠猜测选择目录或确认权限。

使用全新上下文，不复制主任务全部历史。角色配置见 [android-device.toml](../../../.codex/agents/android-device.toml)，使用 `gpt-6-luna` 与 `low` 推理。客户端尚未发现该角色时，可显式以同样模型和推理设置启动普通子 agent，并传入本技能和角色配置中的完整行为约束；模型不可用时报告，不静默回退到更贵模型。不能只指定模型而遗漏护栏。

安装／卸载、清除数据、删除或写源文件、修改设置、撤销授权、重启／强停等动作不属于该轻量角色；由主 agent 依据本次授权和项目约束处理。登录由用户完成。未知系统页面不点击返回／主页探索恢复，停止并交回设备执行权。

主 agent 核对简短结果和必要证据，再记录实际验收层次。点击成功仅代表动作执行；目录授权还需核对返回 debug 应用的状态／真实持久授权，元数据导入还需核对任务和导入结果。

详细产物写入被忽略的 `app/build/verification/<本轮目录>/`，只向主上下文返回状态、检查项及路径。helper 默认只保存短结果 JSON，不保存完整 XML。轻量角色不得启用 `--save-xml` 或自主截图，需要时由主 agent 核对当前页面并提供必要截图。不要采集登录页、令牌或私有账号数据；XML 和截图也可能包含敏感内容，不提交原始产物。
